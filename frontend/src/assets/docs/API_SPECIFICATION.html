🧾 MicroBill API Specification

👥 Demo Users

Admin: admin@demo.com / Admin#123

User: user@demo.com / User#123

🔐 Authentication Service (Port 8081)

POST /api/auth/login

Authenticate user and get JWT token

{
  "username": "admin@demo.com",
  "password": "Admin#123"
}
POST /api/auth/validate

Validate JWT token

📊 Management Service (Port 8082)

GET /api/customers

Get paginated list of customers

POST /api/customers

Create new customer

{
  "name": "New Customer Corp",
  "docNumber": "999888777",
  "email": "contact@newcustomer.com",
  "address": "456 Business Ave"
}
GET /api/products

Get paginated list of products

POST /api/products

Create new product

{
  "code": "PROD-001",
  "name": "New Product",
  "price": 299.99,
  "stock": 50,
  "taxRate": 0.19
}

🧾 Billing Service (Port 8083)

GET /api/invoices

Get paginated list of invoices

POST /api/invoices

Create new invoice with automatic calculations

{
  "customerId": 1,
  "providerId": 1,
  "items": [
    {
      "productId": 1,
      "quantity": 2,
      "unitPrice": 1500.00,
      "taxRate": 0.19
    }
  ]
}
POST /api/invoices/{id}/generate-report

Generate PDF report for invoice

🤖 AI Service (Port 8084)

POST /api/ai/recommendations?customerId={id}

Get AI-powered product recommendations

POST /api/ai/anomaly-score

Detect anomalies in invoice data

{
  "customerId": 1,
  "total": 15000.00,
  "items": [...]
}
